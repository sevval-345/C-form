# C-form

Bu repository, C# kullanılarak geliştirilen Windows Forms uygulamalarının örneklerini içerir. Öğrenme amaçlı hazırlanan projeler arasında form geçişleri, hesap makinesi, renkler dünyası, pizza uygulaması ve benzeri küçük uygulamalar yer almaktadır.

## İçerik

Bu klasördeki çözüm dosyaları (`.sln`):

- `ders1 yg.sln` - temel C# form uygulamaları
- `formlar arası geçiş.sln` - formlar arasında geçiş örneği
- `formlar arası geçiş 2.sln` - ikinci form geçiş örneği
- `hesap makinesi.sln` - basit hesap makinesi uygulaması
- `pizzacı 2.sln` - pizza sipariş / menü uygulaması
- `renkler dünyası.sln` - renk seçimi ve görsel örnek uygulaması
- `yunus hoca hesap makinesi.sln` - öğretici hesap makinesi örneği

## Proje Hakkında

Bu repo, C# ve WinForms ile arayüz tasarımı, olay tabanlı programlama, form yönetimi ve temel kullanıcı etkileşimi konularını öğrenmek için oluşturulmuştur.

## Gereksinimler

- Visual Studio
- .NET Framework / .NET SDK (projenizin kurulu olduğu sürüme göre)

## Çalıştırma

1. Visual Studio'yu açın.
2. İlgili `.sln` dosyasını açın.
3. `Build` > `Start` veya `F5` tuşu ile projeyi çalıştırın.

## Amaç

Bu repository, C# form uygulamalarıyla ilk adım atmak isteyenler için örnek bir öğrenme setidir.

## Not

Projeler öğrenci/öğrenme çalışmaları niteliğindedir ve geliştirme sürecinde örnek amaçlı hazırlanmıştır.
